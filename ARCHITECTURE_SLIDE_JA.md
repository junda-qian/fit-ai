### AWSリソース構成

| リソース種別 | サービス名 | 数量 | 用途 |
|--------------|------------|------|------|
| **コンピューティング** | AWS Lambda | 1関数 | メインAPIバックエンド (247MB) |
| **データベース** | Amazon DynamoDB | 9テーブル | ユーザープロファイル、ログ、サマリー |
| **ストレージ** | Amazon S3 | 3バケット | フロントエンドホスティング、会話メモリ、RAGドキュメント |
| **CDN** | Amazon CloudFront | 1ディストリビューション | グローバルコンテンツ配信 |
| **API** | Amazon API Gateway | 1 HTTP API | 30以上のRESTエンドポイント |
| **ベクトルDB** | Amazon OpenSearch Serverless | 1コレクション | 健康知識 (4,484ベクトル) |
| **AI/ML** | Amazon Bedrock | 2モデル | Nova Lite LLM + Titan埋込 |
| **IAM** | IAMロール | 1ロール | Lambda実行ポリシー |

## スライド3: 技術スタックとAWSリソース

### フロントエンド技術

| レイヤー | AWS サービス / 技術 | 用途 |
|---------|---------------------|------|
| **フロントエンド** | Next.js 15 + React 19 + TailwindCSS | 静的Webアプリ |
| **CDN** | Amazon CloudFront | グローバルコンテンツ配信 |
| **フロントエンドストレージ** | Amazon S3 | 静的Webサイトホスティング |

### バックエンド技術

| レイヤー | AWS サービス / 技術 | 用途 |
|---------|---------------------|------|
| **API** | Amazon API Gateway (HTTP API) | RESTエンドポイント |
| **コンピューティング** | AWS Lambda (Python 3.12) | サーバーレスバックエンド |
| **フレームワーク** | FastAPI + Mangum | 高性能API |
| **AI/LLM** | OpenAI GPT-4 Turbo + Amazon Bedrock (Nova Lite) | 会話型AI |
| **埋め込み** | Amazon Bedrock (Titan V1 - 1536次元) | セマンティック検索 |

### データ層

| レイヤー | AWS サービス / 技術 | 用途 |
|---------|---------------------|------|
| **ベクトルDB** | Amazon OpenSearch Serverless / FAISS | RAG知識ベース |
| **データベース** | Amazon DynamoDB (9テーブル、従量課金) | ユーザーデータ・ログ |
| **バックエンドストレージ** | Amazon S3 (2バケット) | 会話メモリ、RAGドキュメント |

### インフラ・外部サービス

| レイヤー | AWS サービス / 技術 | 用途 |
|---------|---------------------|------|
| **IaC** | Terraform | インフラ自動化 |
| **外部API** | USDA FoodData API | 栄養データベース |

### DynamoDB テーブル構成（9テーブル）

| テーブル名 | 主キー | GSI | 用途 |
|-----------|--------|-----|------|
| **user_profiles** | user_id | なし | ユーザープロファイル |
| **workout_plans** | id | UserIdIndex | ワークアウトプラン |
| **nutrition_logs** | id | UserIdDateIndex | 栄養ログ |
| **workout_logs** | id | UserIdDateIndex | ワークアウトログ |
| **body_logs** | id | UserIdDateIndex | 体組成ログ |
| **daily_summaries** | id | UserIdDateIndex | 日次サマリー |
| **user_exercises** | id | UserIdIndex | ユーザーエクササイズ設定 |
| **training_recommendations** | id | UserIdCreatedAtIndex | トレーニング推奨 |
| **training_progress_summaries** | id | UserIdWeekIndex | トレーニング進捗サマリー |

### コア機能まとめ

1. **エビデンスベース・ヘルスチャットボット**: 4,484の医学知識ベクトルを使用したRAGシステム
2. **栄養トラッキング**: USDA統合によるAI搭載カロリー・マクロ分析
3. **ワークアウト分析**: トレーニングボリューム分析・パーソナライズド推奨
4. **マルチエージェントAI**: 専門エージェント（Coach、Nutrition、Training）の協調動作
5. **リアルタイムインサイト**: トレンド検出を伴う日次・週次サマリー
