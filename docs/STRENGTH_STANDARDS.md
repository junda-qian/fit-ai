# Strength Standards for Training Status Assessment

Reference: [ExRx.net Strength Standards](https://exrx.net/Testing/WeightLifting/StrengthStandards)

**Age Group:** 18-39 years

## Purpose

This document provides strength standards to automatically determine a user's training status based on their performance in key compound lifts. Training status is used to set appropriate training intensities and volume recommendations.

## 1RM Calculation Formula

```
1RM = Weight × (1 + (Reps / 30))
```

Example: If you lifted 80kg for 5 reps:
```
1RM = 80 × (1 + (5 / 30))
1RM = 80 × 1.167
1RM = 93.3 kg
```

## Training Status Levels

1. **Untrained** - No regular resistance training
2. **Novice** - 2-6 months of training
3. **Intermediate** - 6 months - 2 years of consistent training
4. **Advanced** - 2-5+ years of consistent training
5. **Elite** - Competitive level strength

## Key Exercises for Assessment

The following 4 exercises are used to determine training status:
- **Bench Press** - Horizontal push strength
- **Overhead Press (Press)** - Vertical push strength
- **Deadlift** - Hip hinge and posterior chain strength
- **Squat** - Lower body strength

## Usage Notes

### Bodyweight Categories

If a user's bodyweight falls between categories, use the **closest category**.

### Multiple Exercise Assessment

When determining overall training status from multiple lifts:
1. Calculate status for each of the 4 key exercises
2. Use the **median** status as the overall training status
3. This prevents outliers from skewing the assessment

Example:
- Bench Press: Intermediate
- Overhead Press: Novice
- Deadlift: Intermediate
- Squat: Advanced

**Overall Status: Intermediate** (median of [Novice, Intermediate, Intermediate, Advanced])

### Missing Data

If a user hasn't performed all 4 key exercises:
- Use available exercises for assessment
- Require at least 1 key exercise for status determination
- Default to "Novice" if no data available

### Training Status → Intensity Recommendations

From `docs/WORKOUT_PLANNER.md`:

| Training Status | Compound Exercises | Isolation Exercises |
|----------------|-------------------|---------------------|
| Novice         | 60% intensity     | 60% intensity       |
| Intermediate   | 80% intensity     | 65% intensity       |
| Advanced       | 85% intensity     | 70% intensity       |

### Automatic Status Updates

The Weekly Progress Analyzer Agent should:
1. Calculate 1RM from recent workout logs
2. Compare against strength standards
3. Update training status if user has progressed
4. Adjust training intensity recommendations accordingly
5. Notify user of status changes
